# Walmart Customer Analytics Dashboard 📊

## 📌 Project Overview
This project uses Power BI to analyze Walmart customer data and explore customer behavior, retention, churn, and loyalty program performance.

The goal is to identify customer trends and generate insights that can help businesses improve customer retention and make data-driven decisions.

## 🎯 Project Objectives
- Analyze customer churn and retention.
- Understand customer purchasing behavior.
- Evaluate customer loyalty tiers.
- Explore promotion effectiveness.
- Compare customer churn across regions and preferred channels.
- Analyze Customer Lifetime Value (CLV).
- Identify potential opportunities to improve customer retention.

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **Data Analytics** – Customer behavior and retention analysis

## 🔍 Key Areas of Analysis
1. **Customer Churn:** Explore churn patterns across customer segments.
2. **Customer Retention:** Examine customer retention trends.
3. **Customer Loyalty:** Analyze customer loyalty tiers.
4. **Promotion Analysis:** Explore promotion effectiveness.
5. **Regional Analysis:** Compare customer performance across regions.
6. **Customer Lifetime Value:** Examine customer value metrics.

## 💡 Business Applications
The analysis can help businesses:
- Identify customer segments that may need retention strategies.
- Understand customer loyalty and purchasing patterns.
- Evaluate promotional activities.
- Support data-driven customer relationship decisions.
